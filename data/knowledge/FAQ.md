# 智服客户服务 FAQ

版本：2.0

文档编号 SS-FAQ-2026-02 · 生效日期 2026-10-22。本文是虚构智能家居业务的支持知识；规格以产品手册、规则以售后政策为准。如资料冲突，停止承诺并转人工。

## 门锁没电了，怎样进门？
智安 S1 可使用外侧 Type-C 应急供电口连接符合要求的移动电源，然后验证已录入的指纹或密码，也可使用机械钥匙。Type-C 只应急供电，不充 AA 电池。不要暴力撬门或拆锁。无法确认设备型号或安全状态时，提交服务升级单并联系安装专员。

## 指纹识别不灵敏怎么办？
保持手指和感应区清洁干燥，换已录入的另一根手指，必要时在安全情况下重新录入同一手指多个角度。手指湿润、磨损或传感器污渍可能影响识别；这不是对硬件故障的最终结论。若多种解锁方式均失败，使用机械钥匙或应急供电并转人工，禁止连续拆卸。

## 为什么设备搜不到 Wi-Fi？
S1、C2、L1、P1、H1 仅支持 2.4GHz Wi-Fi。先确认路由器开启 2.4GHz，手机和设备在同一网络，关闭 AP 隔离，检查设备进入配网状态。双频同名网络可暂时分开名称测试。T1 是 Zigbee 温湿度计，通过 H1 配对，不会直接出现在 Wi-Fi 列表中。

## 摄像头录像是不是必须付费？
守望 C2 的实时预览和本地 microSD 卡录像无需购买云服务，存储卡需自备，支持 16–128GB Class 10。云存储是可选服务，样例价格 19 元/月，试用 7 天。离线期间能否录像取决于是否装卡且有电，不能保证云端存在录像。客服不能访问用户视频内容。

## 摄像头可以装室外、支持防水吗？
C2 只用于室内干燥环境，产品手册没有防水等级，不适合室外雨淋、浴室或强水汽处。不要凭外观推断防水。对户外设备选型需求，可提交人工核验，不推荐使用 C2 替代室外摄像头。

## 灯泡断网还能开吗？
晨光 L1 断网保持最后亮度，墙壁开关仍可开关灯，远程控制和云端定时不可用。墙壁开关平时保持通电，不能与传统调光器混用。恢复联网后同步场景，但不保证补执行断网期间的任务。

## 插座能控制空调、电暖器吗？
轻控 P1 最大 10A / 2200W。先核对用电器额定功率及启动电流，不得接超过限值的空调、电暖器或多个串联排插。外壳异常发热、焦味、冒烟时立即断电并停止使用。客服不能指导带电维修或承诺大功率设备可用。

## 温湿度计必须买网关吗？
是，知温 T1 使用 Zigbee 3.0，必须搭配联家 H1 网关，不能直连 Wi-Fi。H1 最多接入 64 台兼容子设备。T1 用于家居舒适度参考，不是医疗或工业精密仪器。

## 是否支持 Matter、苹果 HomeKit 或小米生态？
联家 H1 不支持 Matter、Thread 和 HomeKit；本项目仅确认产品手册列明的智服设备。不承诺接入小米或其他第三方平台。缺少明确兼容清单时，客服说明无法确认并提供人工核验入口，不能自行推断。

## 怎样查订单和物流？
进入「我的订单」选择订单，也可向客服发送完整 SS 开头订单号查询物流。明确订单号的纯物流问题走确定性订单节点，通过 MCP 查询本人订单，整个回答可不调用 DeepSeek；订单节点不冒称自主 Agent。系统展示持久化的模拟状态与运单号，没有连接真实物流。普通用户无法查询其他用户订单，缺少订单号或历史中有多个订单时需要先明确订单。

## 可以退货吗？多久退款？
签收后 7 日内可在订单详情提交整单退货退款申请，用户再次确认后还需要管理员核验。商品完整和是否可再次销售由人工审核，不由 Agent 判断。只问退款政策或收到 Agent 建议不会创建申请；创建、确认、审核是三个不同步骤。管理员批准才返还模拟余额，历史演示订单不会增加钱包资金。超过自动窗口、安装过或有争议时走人工服务单。

## 重复点击退款会扣款或退两次吗？
退款不会扣款。系统按用户、订单和整单退款类型生成业务幂等键，数据库对订单和幂等键设置唯一约束，重复申请返回同一记录；确认操作也可重复。网络超时后可以刷新查看原记录。系统只记录模拟资金处理，不调用真实支付机构。

## 转人工后去哪里看结果？
先填写并确认服务升级单，提交成功获得工单编号。管理员处理完成后，结果写回原客服会话，并在服务单中显示状态。可在客服页「我的服务升级单」查看。转人工为异步协作，没有实时在线人工聊天；工作时效为样例服务目标。

## AI 的回答有哪些依据？
产品和政策回答检索产品手册、FAQ、售后政策、交易与账号四份版本化文档，回答底部展示引用片段和来源。订单事实来自订单工具。无足够证据、工具超时或超出权限时，系统说明限制并提供人工服务。AgentOps 展示路由依据、工具调用和检索结果，是审计摘要，不显示模型隐藏推理。

## 管理员模式能看什么？
管理员必须输入独立管理员账号和密码登录，身份由服务器保存，普通注册只产生客户账号，没有角色切换入口。管理员可以按客户查看订单、推进模拟物流、审核退款、处理人工服务单、复核答案反馈和查看运行追踪。客户只能查看自己的订单、会话和任务；修改前端显示不能获得管理员权限。忘记客户密码需联系管理员重置，本版本没有邮件或短信找回。
