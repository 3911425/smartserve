# ServicePilot 技术路线

本路线记录工程演进方向，不承诺上线日期。改进以失败数据和可复现实验为依据，未完成项不作为当前能力。

## 已完成

- 客户注册、可撤销会话、CSRF、角色与数据归属校验。
- 模拟钱包与库存购买、一次性随机配送、请求幂等及唯一资金流水。
- 统一售后资格、用户版本确认、管理员审核、撤回与重提历史。
- 产品/售后领域工具循环、确定性订单节点、HTTP MCP及工具白名单。
- 本地BGE、BM25/向量/融合检索、证据门槛、引用与事实核验。
- 持久任务、租约、检查点、取消、SSE续读、调用遥测和反馈复核。
- 三种运行拓扑及跨数据库回归，固定检索/离线任务集。

具体边界及证据见[验证报告](06-评测与验证报告.md)。

## 优先改进

| 方向 | 问题与计划 | 验收依据 |
| --- | --- | --- |
| 在线Agent质量 | 增加真实模型下的售后、多轮、复合意图、注入与故障集 | 人工复核标签、真正保留集、任务结果、成本与延迟分布 |
| 检索与证据 | 扩充近域负例与语料，按失败分布验证重排和门槛 | Recall/MRR/可用证据覆盖/误接受，保留基线与消融结果 |
| 索引发布 | 索引构建与发布分离，支持切换和回滚 | 并发查询不读到部分新索引，多实例revision一致 |
| 任务运行 | 事件留存、故障演练、多实例领取与全局反滥用 | 崩溃/重投/取消/旧租约验证，不承诺外部恰好一次 |
| 部署与安全 | HTTPS、网络隔离、管理员恢复、输入敏感信息处理 | 干净环境部署、备份恢复、最小权限与运行记录 |
| 容量 | 分开测订单读取、购买事务和Agent排队 | 明确硬件、数据量、实例数、模型桩/真实模型及指标 |

## 按需求评估

- 图片辅助售后：识别有限的设备型号和外观现象，经用户确认再检索或形成工单；不凭图片自动鉴定责任或退款。
- 评论或推荐：在数据、权限与验收规则完整后小范围引入。
- 服务拆分：出现独立扩缩容或发布需求时优先评估Agent worker、索引任务；当前保持模块化单体。
- 真实支付和物流：需另行设计验签、回调、对账、补偿及运营流程，不能直接替换模拟接口文案。

每次变更记录问题、基线、假设、验收指标、失败案例和回退方案；未证明提升的实验也保留结果。
