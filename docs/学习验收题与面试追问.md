# 学习验收题与面试追问

这是针对当前源码的自测，不是任何公司的官方题库或录用标准。每题按0至3评分：0说不清；1能解释概念；2能定位源码/数据并复现；3能现场修改、验证并解释取舍。先作答，再核对提示，避免背提示冒充理解。

## 产品与架构

| 问题                      | 合格答案必须覆盖                                            | 进一步追问                         |
| ------------------------- | ----------------------------------------------------------- | ---------------------------------- |
| 这个项目解决什么问题？    | 智能家居选购/使用/订单/售后；AI主线及人工闭环；模拟支付物流 | 去掉AI之后业务是否仍正确？         |
| 哪些是真Agent？           | 两领域模型工具循环；主管路由；订单确定性节点                | 为什么不让每个节点都调用模型？     |
| 三种profile怎么影响运行？ | 数据源/向量计算/MQ缓存，Compose覆盖                         | 本机订单为什么Docker里看不到？     |
| 为什么仍是单体？          | 业务边界与部署成本；MCP不等于微服务                         | 第一个值得独立扩缩容的部分是什么？ |

## 账户、SQL与事务

| 问题                         | 源码与实验提示                                                             | 进一步追问                                  |
| ---------------------------- | -------------------------------------------------------------------------- | ------------------------------------------- |
| 用户篡改role能成管理员吗？   | AuthController.Registration没有role；AuthService固定CUSTOMER；Access.admin | 前端隐藏入口和后端权限有什么区别？          |
| BCrypt和SHA-256为什么都用？  | 低熵密码/高熵会话token，成本/查询撤销                                      | 为什么不用明文或直接MD5？                   |
| Cookie为什么还需CSRF？       | 自动携带、HttpOnly/SameSite/Origin/CSRF分工                                | XSS发生时这些机制各能挡什么？               |
| 同键16次购买为什么只扣一次？ | 客户行锁、请求哈希、唯一键、事务                                           | 已提交响应丢失如何重试？同键改数量呢？      |
| 两个客户抢最后一件呢？       | 库存条件更新影响行数，非负CHECK                                            | 只查库存再update为什么不够？                |
| 扣库存后余额不足怎么办？     | RuntimeException事务整体回滚                                               | catch后返回false还会回滚吗？                |
| 什么地方用了乐观版本？       | 管理员状态推进/退款审核/工单                                               | 同时有行锁与version是否重复？分别保护什么？ |
| 为什么历史退款不返钱包？     | LEGACY_DEMO未扣余额，不得造钱                                              | 接真实支付后需要什么对账状态？              |
| @Transactional有啥失效场景？ | 代理调用、自调用/private、异常类型                                         | 长HTTP模型调用为什么不放大事务里？          |

现场题：库存只剩1，两个不同客户同时购买，画SQL执行顺序并说明余额何时变动。再让一个响应超时，解释重试不会再次买走第二件。找一个不能保证的场景，不能只说“绝对不会出问题”。

## Agent、MCP与模型调用

| 问题                       | 合格答案必须覆盖                                        | 进一步追问                         |
| -------------------------- | ------------------------------------------------------- | ---------------------------------- |
| 物流查询用了几次远程模型？ | 明确完整订单号纯物流路径可0次，按model_call核验         | 模糊复合问题为什么不同？           |
| 产品Agent怎么调用工具？    | tool定义→模型请求→白名单/参数→MCP→tool结果→下一轮       | tool_call_id为什么要匹配？         |
| 模型循环如何停止？         | 轮数、任务调用预算、工具/搜索限制、重复参数、超时和回退 | 多个工具同轮返回如何计数？         |
| 模型能退款吗？             | prepareRefund只读建议，三步业务确认                     | 模型说“我已退款”怎样防与发现？     |
| MCP身份是谁决定的？        | 受信服务token/后端Actor，额外userId拒绝                 | 把该端点公开有什么风险？           |
| 为什么同时用LC4j和LG4j？   | 模型消息/工具接口 vs 图/状态/检查点                     | 如果不用图框架可否实现？代价在哪？ |
| 多轮记忆怎么做？           | 最近9条/6000字符、轻量指代查询拼接                      | 多订单、旧意图和截断带来什么风险？ |
| 503重试怎样计费追踪？      | 每次attempt独立、失败用量null、账单供应商准             | 重试风暴和全局并发是否已解决？     |

现场题：给模型返回一个越权工具请求，再给一个重复搜索请求，指出哪个判断拒绝、下一轮模型得到什么、是否已有业务副作用。用本地协议桩验证，不能只读提示词回答。

## RAG与质量

| 问题                   | 合格答案必须覆盖                            | 进一步追问                       |
| ---------------------- | ------------------------------------------- | -------------------------------- |
| 三种模式向量化不同吗？ | 都是BGE512，差在保存与计算位置              | H2怎样保存float数组？            |
| 什么是chunk元数据？    | 来源/标题/范围/版本/hash/modelID            | 改模型但不重建会怎样？           |
| 为什么用BM25和向量？   | 字面术语/语义改写互补，固定数据验证         | 本次混合MRR一定最高吗？          |
| 是否用了reranker？     | 当前非神经融合，未用Cross-Encoder           | 真重排增加什么成本，何时引入？   |
| Recall高为何仍不回答？ | 排序命中和accepted分开，门槛/领域限制       | 漏掉T1中文边界的问题如何定位？   |
| 如何测无依据回答？     | 负例/注入/未知型号/证据审查，不能宣称零幻觉 | judge自信但错误怎么办？          |
| AgentOps能当评测吗？   | 它记录过程，评测有数据/标签/指标/回归       | 一次失败怎么从trace进入评测集？  |
| RAGAS用了没有？        | 本版本自定义judge，不能冒称RAGAS            | 若替换评测库，数据契约如何保留？ |

现场题：打开一条失败用例，先判定缺文档、召回、排序、门槛还是生成，再改一个变量做对照。问“98%”时必须说分母、TopK、标注来源、可见开发集、同义证据是否穷尽、负例比例和误接受，而不是只说高准确率。

## 一次60分钟模拟答辩

前5分钟演示业务，接着10分钟画购买与客服时序；15分钟深入事务/权限；15分钟深入Agent/RAG；最后15分钟根据一个失败现场定位并提出最小修复。另安排30至60分钟实现任务，独立完成后跑针对回归。

进入下一阶段的参考门槛：安全/资金类题不能有关键错误；核心链路至少达到2分；任选一条能达到3分；至少讲清两个真实失败和三个尚未实现的能力。这个门槛用于自我检查，不代表某公司通过线。
