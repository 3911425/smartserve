# 可靠性、权限与安全边界

## 任务交付语义

HTTP创建任务先提交持久记录，再投递run_id。agent_run的QUEUED状态作为可重试任务源；每5秒扫描至多16个任务重新唤醒。消息队列为at-least-once思路，消费者用QUEUED→RUNNING条件更新保证重复消息不会同时拿到执行权。

本地线程池4线程、64等待位，队列满不丢已持久任务，后续扫描重派。模型并发限4，单次超时45秒，LangChain4j至多1次重试。图递归上限16，固定业务枚举避免无限工具循环。模型请求与业务写操作的重试语义分开：退款由服务层幂等处理，不能简单重复真实付款。

## Checkpoint和执行租约

原生LangGraph4j Saver持久保存图节点状态。节点完成后才能形成该节点检查点；进程在节点内中断，恢复可能重做该节点。因此工具必须只读或幂等，检查点不能替代幂等。

RUNNING超过180秒无更新时重回QUEUED。节点事件刷新updated_at；正常模型最长两次45秒，低于当前租约。数据库读与控制更新处在独立短事务，不把模型调用长时间放在业务数据库事务里。

当前租约没有 fencing token。极端暂停超过180秒后旧执行者仍恢复运行时，可能产生重复回答或竞争完成记录；退款的数据库约束仍保护业务申请。正式多Worker环境需增加lease_owner、lease_version、心跳和带版本的完成更新，并进行kill/restart/网络分区验证。没有把当前方案描述成严格exactly-once。

## 降级矩阵

| 故障             | 行为                       | 数据影响         |
| ---------------- | -------------------------- | ---------------- |
| DeepSeek路由失败 | 确定性规则路由             | 保留事件         |
| 生成/审查失败    | 返回检索原文证据           | 不编造额外事实   |
| MCP业务工具失败  | 说明未完成，建议人工       | 不宣称执行成功   |
| Redis不可用      | 直接检索与计算             | 持久历史不受影响 |
| RabbitMQ投递失败 | 保留QUEUED并重试           | 持久任务可恢复   |
| LangSmith不可用  | 本地记录保留，警告事件     | 不阻断客服结果   |
| SSE断开          | 用eventId补发或GET查询终态 | 不取消已持久任务 |
| PostgreSQL不可用 | 不能提交任务/业务          | 不用内存假装成功 |

## 身份与授权

DEMO_ACCESS开启时服务器签发HMAC短期令牌，客户端不能只修改一个role字段就获得管理员权限。服务器在每次订单、退款、会话、工单和运行访问时检查owner_id；管理员权限单独判断。退款查重先做授权，避免旧记录泄漏。

演示角色接口本身允许公开切管理员，所以它仅用于隔离的体验环境；签名不能把开放的角色签发变成商业认证。正式部署关闭该接口，接真实OIDC/JWT与租户权限。目前只有预配置静态客户/管理员凭证支持，不是完整身份平台。

MCP使用独立服务token，Nginx默认阻止浏览器访问。可信服务可携带用户上下文，所以泄露该token风险很大；正式部署需要mTLS/OAuth、服务身份、细粒度scope与审计。没有将MCP协议本身当授权实现。

## Prompt注入与资料边界

模型没有数据库或任意文件读写工具，不能动态添加权限。输出route只接受有限枚举；业务工具参数服务端验证；产品证据被明确标注为数据，不能执行其指令。答案引用只允许当前片段ID，独立审查失败回退证据。

这些措施减少越权与无据回答，但不是全面对抗证明。用户输入和知识库都可能携带恶意指令，正式环境应加入系统性的攻击测试、来源审核、结构化输出和敏感内容处理。没有让模型自由执行Shell、SQL、任意URL或真实资金动作。

## 追踪隐私与密钥

Key只在`.env`或进程环境，模型SDK关闭请求/响应日志。LangSmith默认发送问题长度、用户哈希、节点名称、状态、耗时和Token，不发送原始对话、联系方式、地址或工具完整输出。本地AgentOps保存业务审计信息，只对授权身份返回。

`.env`、`.local`、运行数据库、日志、node_modules、target均被忽略。上传前检查Git暂存清单与高熵Key模式。`.env.example`只提供变量，不含真实凭证。截图只用虚构业务内容与example.invalid联系方式。

## Web边界

前端Markdown经DOMPurify清理再显示，避免用户文本成为脚本。静态资源只开放images目录。接口字段有长度、枚举、确认和类型检查，错误不回显数据库SQL和Key。Compose端口绑定127.0.0.1。

当前没有完整用户限流、WAF、上传扫描、CSRF/OIDC套件、生产密钥轮换与策略引擎。Bearer令牌保存在浏览器sessionStorage，真实部署需评估XSS、token生命周期和HttpOnly会话等方案。对外发布前按真实威胁模型补齐。
